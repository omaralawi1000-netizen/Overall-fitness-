# docs/ layout

- `BRIEF.md`: the whole job. Read first.
- `PROGRESS.md`: what is done and the exact next step.
- `TASTE.md`, `VISION.md`, `COACH.md`, `LESSONS.md`, `INTERVIEW.md`, `INVENTORY.md`, `concepts.md`, `blur-test-plan.md`: decisions and rules for the app.
- `inspiration/`: design only. `notes.md` is what Omar likes, `web-references.md` has the links, the numbered images are screenshots.
- `research/`: findings.
  - `tech-scan-2026-11-01.md`: the tech scan (pricing, voice, memory, motion, food data). Links it already cites are not repeated below.
  - `sources/`: link lists, one file per topic, one line per link. References, not rules.
    - `claude-code.md`: working with Claude Code.
    - `coach-ai.md`: Coach evals, model comparisons, papers.
    - `health-data.md`: Health Connect, HealthKit, Capacitor, browser storage.
    - `food.md`: Open Food Facts.
    - `competitors.md`: Hevy, Strong, Fitbod, Bevel, WHOOP, Fitbit.
    - `privacy.md`: GDPR.
- `history/`: old material kept for the record. History, not direction.

Read only the reference file for the topic you're working on.
