# Health data and platform sources

References for reading health data and for web/PWA storage and rendering limits. Not rules.

- https://developer.android.com/health-and-fitness/health-connect/data-types : what Health Connect can hold.
- https://developer.android.com/health-and-fitness/health-connect/read-data : how to read it.
- https://developer.apple.com/documentation/healthkit/ : Apple HealthKit overview.
- https://developer.apple.com/documentation/healthkit/authorizing-access-to-health-data : asking permission for health data.
- https://capacitorjs.com/docs : wrapping the web app as a native app.
- https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria : how much the browser stores, and when it deletes it.
- https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame : frame-timed animation.
