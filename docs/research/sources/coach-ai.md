# Coach and AI sources

References for building and testing the Coach. Not rules; the Coach spec is docs/COACH.md.

## Building and testing
- https://www.anthropic.com/research/demystifying-evals-for-ai-agents : how to evaluate agents (for the Coach exam).
- https://www.anthropic.com/research/effective-context-engineering-for-ai-agents : what to put in the model's context.
- https://www.promptfoo.dev/docs/intro/ : promptfoo, a tool for running prompt tests.
- https://www.promptfoo.dev/docs/guides/ : promptfoo how-to guides.
- https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html : defending against prompt injection.

## Model comparisons
- https://artificialanalysis.ai/leaderboards/models : model quality, speed and price.
- https://artificialanalysis.ai/speech-to-text/non-streaming/ : speech-to-text comparison.
- https://arena.ai/leaderboard/chat/text : crowd-voted chat ranking.
